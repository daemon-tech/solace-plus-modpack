# Solace Plus changelog
## 0.1.0 (draft)
- Initial pack for Minecraft 26.3 (Fabric 0.19.5), client-side only
- Performance: Sodium 0.9.2, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, More Culling, BadOptimizations, Dynamic FPS, Sodium Extra
- Visuals: Iris 1.11.7, Continuity, Fusion, Whimscape (by kavast), Falling Leaves, Subtle Effects, Particle Interactions, LambDynamicLights, EMF/ETF, Polytone, Smooth GUI, Chat Heads
- Long view distance: Bobby
- Updated Fabric API to 0.164.0
- Added Fresh Animations, Fresh Animations: Extensions and Player Extension (by FreshLX) for animated mobs and players
- All resource packs are enabled by default (Whimscape below the Fresh Animations packs)
- Added AmbientSounds (+ CreativeCore) and Presence Footsteps for cozy ambience
- Added YOSBR: default options (enabled resource packs) only apply on first install and no longer overwrite your settings on updates
- Removed Camera Overhaul
- Added Solace Shaders 0.29-dev, enabled by default on first install
